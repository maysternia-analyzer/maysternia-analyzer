# Майстерня Аналізатор

Платформа AI-аналитики звонков и занятий онлайн-школы «Майстерня скілів» (курс «Код Харизми»),
по функциональности аналогичная SalesUp: сервис сам забирает записи встреч из Zoom, получает
транскрипцию и с помощью Claude разбирает каждую разговор по настраиваемому чек-листу.

**Что получает руководитель**
- **Карточка звонка**: оценка, шанс сделки, «температура» лида, резюме; чек-лист с цитатами и
  таймкодами (клик — переход к моменту в записи); возражения клиента с оценкой отработки и
  лучшим ответом; риски сделки; договорённость о следующем шаге; данные клиента (цель, боли,
  вопросы, бюджет); ключевые моменты; фразы для коучинга; готовый скрипт следующего контакта.
- **Команда**: рейтинг с трендом к прошлому периоду, выполнение каждого пункта чек-листа
  (слабые места, клик — список звонков с цитатами), частота возражений и рисков, реальная
  конверсия и выручка, точность прогноза AI.
- **Аналитика речи**: доля речи менеджера и клиента, количество вопросов, самый длинный монолог.
- **Профиль менеджера/тренера**: динамика оценок, карта навыков, типичные ошибки, AI-план развития.
- **Настраиваемость**: чек-листы (критерии, описания, веса, инструкции), описание компании,
  модель Claude, пороги, параметры Zoom — всё в интерфейсе, без программиста.
- **Уведомления в Telegram**: итог каждого анализа, тревоги (низкая оценка, «горячий» лид без
  следующего шага), ежедневный отчёт руководителю.
- **Интеграции**: исходящий вебхук с HMAC-подписью (CRM, Make, Zapier, n8n), экспорт в Excel (CSV).
- **Роли**: администратор, керівник (все записи), менеджер/тренер (только свои записи, без изменений).
- Поиск по всем разговорам, AI-аналитика по базе (портрет ЦА, топ потребностей и возражений).

## Как это работает (коротко)

```
Zoom (облачная запись) ──webhook──►  /zoom/webhook ─┐
        └───── поллер каждые 5 мин (резерв) ────────┤  запись в очереди (БД, status=queued)
Ручная загрузка VTT / TXT / аудио ──────────────────┘
                                                     ▼
                         фоновый воркер (1 процесс-лидер, до 2 задач параллельно)
                         1. транскрипция с таймкодами: VTT от Zoom (секунды) или Whisper
                         2. тип записи и имя ведущего (эвристика / Claude)
                         3. AI-анализ Claude по текущему чек-листу (JSON по схеме)
                         4. уведомления: Telegram, вебхук
                                                     ▼
                  карточка звонка · дашборды · команда · профили · ежедневный отчёт
```

Очередь хранится в БД, поэтому рестарт/деплой Railway не теряет записи: незавершённые
задачи возвращаются в очередь автоматически, временные ошибки (сеть, 429/5xx) повторяются.

## Быстрый старт локально

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env          # заполнить ANTHROPIC_API_KEY и SECRET_KEY
python create_admin.py        # первый администратор
python app.py                 # http://localhost:5050
```

Без `DATABASE_URL` используется SQLite (`data.db`). Без ключей Zoom работает только ручная
загрузка; без `OPENAI_API_KEY` — только загрузка готовых транскрипций VTT/TXT.

## Тесты

```bash
pytest -q                                                    # SQLite, все внешние API замоканы
TEST_DATABASE_URL=postgresql://user:pass@localhost/test pytest -q   # те же тесты на PostgreSQL
FFMPEG_TEST_PATH=/usr/bin/ffmpeg pytest tests/test_transcription.py # + реальная нарезка аудио
```

286 тестов: БД и миграции, очередь и восстановление, Zoom API/webhook, конвейер обработки,
AI-слой (схемы, ошибки, нормализация, старый формат), чек-листы и настройки, уведомления,
командная аналитика, роли и доступ, веб-слой (CSRF, безопасность, все страницы).

## Структура

```
app.py                  маршруты Flask, роли, страницы, админка, webhook
database.py             PostgreSQL/SQLite, миграции, очередь, дедупликация Zoom, поиск
security.py             SECRET_KEY, CSRF, лимит попыток входа, безопасные редиректы
services/
  pipeline.py           конвейер: приём Zoom-встреч, обработка записи, повторы
  background.py         фоновый воркер: лидер (flock), очередь, поллер, ежедневный отчёт
  analysis.py           промпт и JSON-схема из чек-листа, нормализация карточки звонка
  checklists.py         настраиваемые чек-листы (критерии, веса, инструкции)
  settings.py           настройки из админки (хранятся в БД)
  team.py               рейтинг, тренды, карта навыков, возражения, риски
  notify.py             Telegram, исходящий вебхук, ежедневный отчёт
  coaching.py           AI-план развития для менеджера/тренера
  insights.py           AI-аналитика по всей базе
  zoom.py, poller.py    Zoom API: OAuth, записи, скачивание, подпись webhook
  transcript_text.py    VTT/TXT → «[ГГ:ХХ:СС] Спікер: репліка», статистика спикеров
  transcription.py      Whisper + ffmpeg (сжатие, нарезка, таймкоды)
  llm.py                клиент Claude, structured outputs, классификация ошибок
  detection.py          тип записи и имя тренера/менеджера
  health.py, timeutil.py
templates/, static/     интерфейс (украинский)
tests/                  pytest
create_admin.py         создать админа / сбросить пароль
sync_zoom.py            ручная синхронизация Zoom из консоли
```
